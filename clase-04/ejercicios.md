# Ejercicios clase 04

## Funcion

1. Crear una funcion que muestre "Hola, mundo"
2. Llamarla dos veces
3. Cambiar el mensaje y volver a ejecutar

## Parametros y argumentos

1. Crear una funcion que reciba una edad y la muestre
2. Crear una funcion que reciba dos numeros y los reste
3. Probar distintos valores

## Return

1. Crear una funcion que devuelva un numero fijo
2. Guardar el valor retornado en una variable
3. Mostrar ese valor por consola

## Función expresada

1. Crear una funcion expresada que muestre un mensaje.
2. Llamarla desde la variable
